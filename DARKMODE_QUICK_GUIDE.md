# 🌙 Dark Mode Quick Guide

## Cara Mengaktifkan Dark Mode

### Method 1: Toggle Button di Header
1. Lihat ke kanan atas layar
2. Klik icon bulan 🌙 di sebelah notification bell
3. Mode akan berubah instantly!

### Method 2: Profile Dropdown
1. Klik profile Anda di kanan atas
2. Pilih "Mode Gelap"
3. Done! ✨

### Method 3: Keyboard Shortcut (Super Fast!)
- **Windows/Linux:** Tekan `Ctrl + Shift + D`
- **Mac:** Tekan `Cmd + Shift + D`
- Toast notification akan muncul! 🎉

## Automatic Behavior

**First Visit:**
- Sistem akan deteksi theme device Anda
- Jika device dalam dark mode → langsung dark mode
- Jika device dalam light mode → light mode

**Next Visits:**
- Mengingat pilihan terakhir Anda
- Tidak peduli system theme berubah

## Troubleshooting

### Dark Mode tidak tersimpan?
```
1. Clear browser cache (Ctrl+Shift+Delete)
2. Refresh halaman (F5)
3. Toggle dark mode lagi
```

### Warna tidak berubah?
```
1. Hard refresh: Ctrl+Shift+R (Windows) atau Cmd+Shift+R (Mac)
2. Check console: F12 → Console tab
3. Pastikan tidak ada error
```

### Reset ke default?
```javascript
// Buka Console (F12), paste command ini:
localStorage.removeItem('my_schuder_theme');
location.reload();
```
